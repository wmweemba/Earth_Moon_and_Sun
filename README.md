# Sun, Earth, and Moon Simulation

This project is a simple visual simulation of the Sun, Earth, and Moon system using HTML and CSS. It demonstrates the concept of orbital motion, where:

- The **Earth** orbits around the **Sun**.
- The **Moon** orbits around the **Earth**.

The simulation uses CSS animations to create a realistic representation of the orbital paths and rotations.

## Features

- **Sun**: A glowing yellow circle representing the Sun at the center of the simulation.
- **Earth**: A blue circular object that orbits the Sun.
- **Moon**: A smaller gray circular object that orbits the Earth.
- **Orbits**: Circular paths for both the Earth and Moon, with smooth animations.

## How It Works

- The **Earth's orbit** is animated to complete one full revolution around the Sun in 36.5 seconds.
- The **Moon's orbit** is animated to complete one full revolution around the Earth in 2.7 seconds.
- The simulation is styled using CSS, with animations defined using `@keyframes`.

## Technologies Used

- **HTML**: For structuring the elements of the simulation.
- **CSS**: For styling and animating the Sun, Earth, Moon, and their orbits.

## How to Run

1. Clone or download this repository.
2. Open the `index.html` file in any modern web browser.
3. Watch the Earth and Moon orbit the Sun!
